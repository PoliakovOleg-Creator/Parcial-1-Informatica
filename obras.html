El código como sistema visual

En lugar de diseñar una imagen de forma directa, Reas desarrolla algoritmos que determinan cómo los elementos se relacionan, se mueven y evolucionan en el tiempo. Este método convierte al código en el núcleo del proceso creativo.

A partir de reglas simples, sus sistemas pueden generar resultados complejos y impredecibles. Esta lógica permite explorar la emergencia, donde patrones y formas surgen de la interacción entre componentes.

Sistemas, reglas y variación

El trabajo de Casey Reas se fundamenta en la idea de que una obra puede ser entendida como un sistema de reglas. Estas reglas definen las posibles interacciones entre los elementos visuales. Este enfoque introduce la variación como un elemento central: cada vez que el sistema se ejecuta, puede producir un resultado diferente.

El rol del artista-programador

El artista asume el rol de programador: diseña el conjunto de instrucciones que dará lugar a múltiples resultados posibles. La autoría se desplaza hacia el diseño del sistema, mientras que la ejecución introduce elementos de autonomía y sorpresa.
