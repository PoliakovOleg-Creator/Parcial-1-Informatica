El código como sistema visual

En lugar de diseñar una imagen de forma directa, Reas desarrolla algoritmos que determinan cómo los elementos se relacionan, se mueven и evolucionan en el tiempo. Este método convierte al código en el núcleo del proceso creativo [6].

A partir de reglas simples, sus sistemas pueden generar resultados complejos и impredecibles. Esta lógica permite explorar la emergencia, donde patrones и formas surgen de la interacción entre componentes [8].

Sistemas, reglas и variación

El trabajo de Casey Reas se fundamenta en la idea de que una obra puede ser entendida como un sistema de reglas. Estas reglas definen las posibles interacciones entre los elementos visuales. Este enfoque introduce la variación como un elemento central: cada vez que el sistema se ejecuta, puede producir un resultado diferente [8, 9].
